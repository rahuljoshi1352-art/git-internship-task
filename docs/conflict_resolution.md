# Conflict Resolution

A merge conflict occurs when two branches modify the same content differently.

## Steps

1. Create two branches from the same base.
2. Modify the same content differently.
3. Push both branches to GitHub.
4. Merge one branch into main.
5. Merge the other branch and encounter the conflict.
6. Open the conflicted file.
7. Choose or combine the required changes.
8. Remove the conflict markers.
9. Run git add.
10. Commit the resolved changes.
11. Push the branch.
12. Merge the Pull Request.

## Commands

git add README.md
git commit -m "Resolve merge conflict"
git push
