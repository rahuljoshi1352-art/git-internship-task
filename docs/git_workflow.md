# Git Workflow

This project demonstrates a basic Git and GitHub workflow.

## Workflow

1. Initialize a Git repository.
2. Configure Git username and email.
3. Connect the local repository to GitHub.
4. Create commits.
5. Create feature branches.
6. Push branches to GitHub.
7. Create Pull Requests.
8. Merge approved Pull Requests.
9. Resolve merge conflicts when necessary.

## Useful Commands

git init
git add .
git commit -m "message"
git checkout -b branch-name
git push -u origin branch-name
git pull
git merge main
